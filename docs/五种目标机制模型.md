
五种目标机制模型：

原子模型：

**完成型（Binary）**：做完即达成，无中间进度。
- 输入：一次“完成”（可撤销）；进度 0/100%；配速只有倒计时

**累积型（Accumulation）**：往一个总量上加，加到目标值。
- 输入：增量 Δ（可负，如存钱有支出），或读数
- 进度：ΣΔ / target
- 配速：expected(t) = target × 已过时间比例；每日还需 = (target − 已完成)/剩余天数 → 超前/落后

**指标达成型（Metric From→To）**：状态量从 A 到 B，读数会回退，是滞后指标。
- 输入：读数（覆盖式）
- 进度：(current − start)/(target − start)，增减方向通用，可为负
- 判定：建议要求连续 N 次或滑动均值达标以滤噪；配速用近期斜率外推预计达成日

**主观/动态型（Subjective/Stream）**：以时间线（Timeline）记录动态为主，进度完全由人主观判断。
- **输入**：一条动态记录（文本/图片） + **手动加减进度百分比（0~100%）**。
- **进度**：直接等于最新一次手动输入的百分比。
- **判定**：用户主观认为达成，或状态切换为“已完成”。

复合模型：

**里程碑/项目型（Milestone）**：由子项组成，进度来自子项。
- 输入：子项完成（子项可以是任意类型，递归）
- 进度：已完成子项/总数，或加权；子项有自身进度时按进度上卷
- 判定：所有“必需”子项完成；子项有各自日期时可算计划 vs 实际
