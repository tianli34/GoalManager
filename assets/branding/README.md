# 北极星 App 图标

## 设计概念

- **北极星**：代表长期方向与值得持续投入的目标。
- **环形轨迹**：代表目标推进过程，而非一次性打勾。
- **轨迹节点**：代表真实发生的更新与阶段性进展。
- **深海军蓝 + 冰青色**：表达理性、专注、稳定和清晰。

## 视觉规范

- 主背景：深海军蓝渐变（#0A1429 → #112544 → #091629）
- 主图形：冰白色八芒星
- 辅助色：青绿色轨迹（#5CCDD5 / #77E2E2）
- 画布：1024 × 1024，满版背景；由 iOS / Android 平台负责圆角或图标遮罩。
- 设计原则：不含文字，在小尺寸下仍能识别。

## 源文件

- `north_star_app_icon.svg`：可编辑矢量主文件。
- 可从 SVG 导出 1024 × 1024 PNG，再按平台规范生成 Android mipmap 与 iOS AppIcon.appiconset 尺寸。

当前提交只增加品牌源文件，不会覆盖现有 Android / iOS 启动图标资源。
